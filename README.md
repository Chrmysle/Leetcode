# Leetcode

用于记录 LeetCode 算法题解，按语言和题号整理，方便复习与检索。

## 目录约定

```text
solutions/
  python/
  java/
  cpp/
```

每道题建议使用 `题号-题目名称` 命名，例如：

```text
solutions/python/0001-two-sum.py
```

## 提交题解

```bash
git pull --rebase
git add .
git commit -m "solve: 0001 two sum"
git push
```

## 题解内容建议

- 简要说明思路
- 标注时间复杂度和空间复杂度
- 保留可直接运行的核心代码
